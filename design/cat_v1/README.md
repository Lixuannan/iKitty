# AI 猫咪 · 角色拆分设计规范 v1.0

> [返回项目 README](../../README.md) · [English design document](../../docs/DOC_EN.md)

面向 **程序驱动** 的 2D 猫咪角色素材（类 Live2D 的简单分层动画），不是一张完整的插画。
所有部件都拆成独立透明 PNG，共用同一套坐标系，可以直接叠加、旋转、缩放、位移、改透明度。

设计规范图：`cat_spec_sheet.png`

## 文件结构

```
design/cat_v1/
├── cat_spec_sheet.png        角色拆分设计规范图（完整角色 + 15 个部件 + 层级关系 + 可动性演示）
├── layers.json               机器可读清单：z 顺序、锚点、包围盒、用途
├── preview_assembled.png     全部图层按 z 叠加后的完整角色（1024×1024 透明底）
├── layers/                   15 个基础图层
└── expressions/              eye / mouth 的表情变体（替换同 z 图层即可）
```

## 坐标系

| 项 | 值 |
|---|---|
| 画布 | 1024 × 1024 px |
| 原点 | 左上角 |
| 单位 | px |
| 对齐 | **所有图层尺寸相同、注册点相同**，直接按 z 从低到高叠加即为完整角色，无需对位 |

因为注册点一致，程序可以：

- 直接叠加还原角色；
- 按 `layers.json` 的 `bbox_px` 裁成精灵图省内存，再用 `pivot_px` 还原锚点；
- 对任意图层单独做仿射变换而不影响其他部件。

## 图层顺序（z 从低到高）

| z | 图层 | 锚点 (px) | 用途 |
|---|---|---|---|
| 00 | `shadow` | 512, 952 | 脚下软阴影，随身体压缩/拉伸改变大小与不透明度 |
| 01 | `tail` | **676, 872**（尾根） | 绕尾根旋转做摇尾；根部埋进身体 |
| 02 | `body` | 512, 952（底部） | 坐姿躯干，底部为缩放/呼吸锚点 |
| 03 | `paw_l` | 428, 819 | 左前爪，可上下位移做踏步/轻点 |
| 04 | `paw_r` | 596, 819 | 右前爪，可上下位移做踏步/轻点 |
| 05 | `ear_l` | **346, 263**（耳根） | 绕耳根旋转：竖起/压平/抖动 |
| 06 | `ear_r` | **678, 263**（耳根） | 绕耳根旋转：竖起/压平/抖动 |
| 07 | `head` | **512, 717**（脖子） | 含脸型、口鼻浅色区、鼻子；锚点在脖子根部，可歪头/摇头 |
| 08 | `cheek_l` | 326, 548 | 左脸颊，可缩放做鼓腮/害羞 |
| 09 | `cheek_r` | 698, 548 | 右脸颊，可缩放做鼓腮/害羞 |
| 10 | `blush` | 512, 504 | 腮红（左右各一在同一层），整体调透明度 |
| 11 | `eye_l` | **401, 399**（眼心） | 左眼虹膜 + 竖瞳；纵向缩放做眨眼/半闭 |
| 12 | `eye_r` | **623, 399**（眼心） | 右眼虹膜 + 竖瞳；纵向缩放做眨眼/半闭 |
| 13 | `eye_highlight` | 512, 399 | 眼睛高光，可单独淡出 |
| 14 | `mouth` | 512, 545 | 默认柔和微笑 |

加粗锚点是实际做动画时会用到的旋转/缩放中心。

## 安全重叠（重要）

分层角色最容易出的问题是「一转就露缝」。本套素材在每个接缝处都留了重叠区：

- `head` 下方有一段脖子延伸区，埋进 `body` 里 —— 头部 ±15° 内旋转不会露出身体上缘；
- `ear_l/r` 的耳根埋进头部内部 —— 旋转时耳根不会飘出脸外；
- `tail` 根部埋进身体内部；
- `paw_l/r` 上端埋进身体内部，垂直位移不会露出断口。

所以变换各部件时不需要额外的遮罩处理。

## 驱动建议

| 动作 | 做法 |
|---|---|
| 呼吸 | `body` 纵向缩放 1.0 ↔ 1.03，锚点底部 (512, 952) |
| 上下浮动 | 全图层统一 `dy` 平移 |
| 眨眼 | `eye_l/r` + `eye_highlight` 纵向缩放 → 0，再回弹；或直接换成 `expressions/eye_*_closed.png` |
| 左右看 | `eye_l/r` 的 `dx` 平移 ±4px，配合 `head` 极小角度旋转 |
| 耳朵抖动 | `ear_l/r` 绕耳根快速 ±10° 来回 |
| 摇尾巴 | `tail` 绕尾根 (676, 872) 缓慢 ±16° 摆动 |
| 身体弹跳 | 全图层 `dy` 上移 + `body` 纵向拉伸 + `shadow` 缩小变淡 |
| 歪头 | `head` 组（head + ear + eye + mouth + cheek + blush）**绕同一个脖子锚点 (512, 717)** 旋转 |
| 害羞 | `blush` 提高不透明度 + `cheek_l/r` 放大 1.1 |
| 困倦 | 换 `expressions/eye_*_closed.png` + `ear_l/r` 向外压平 |

> 注意：歪头这类「头部整体动作」必须让整组绕**同一个**锚点旋转，而不是每个部件绕各自锚点，否则五官会散开。规范图的「可动性演示」一行就是这么做的。

## 表情变体

`expressions/` 中的文件与基础图层同尺寸、同注册点，**直接替换对应 z 的图层**即可：

| 文件 | 替换 | 说明 |
|---|---|---|
| `eye_l_happy.png` / `eye_r_happy.png` | z 11 / 12 | 弯月眼（开心） |
| `eye_l_closed.png` / `eye_r_closed.png` | z 11 / 12 | 闭眼（眨眼/困倦） |
| `mouth_happy.png` | z 14 | 大笑 |
| `mouth_sad.png` | z 14 | 委屈下弯 |
| `mouth_open.png` | z 14 | 张嘴（兴奋/哈欠） |

换弯月眼时建议同时把 `eye_highlight` 设为全透明。

## 设计约束

- 低饱和暖色：主色 `#CFB49F`、身体 `#DFCCBA`、奶油白 `#FDF8F2`、内耳/腮红粉 `#EEA9B4` / `#F0A9B0`；
- 扁平插画风，无写实光影、无 3D、无复杂毛发、无描边；
- 猫耳为明显的尖三角、脸型圆润、鼻口区不突出；
- 无背景、无场景、无文字（规范图除外）。
